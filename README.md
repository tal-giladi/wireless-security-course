# Wireless Security & Wi-Fi Penetration Testing

A hands-on, up-to-date course that takes a technical learner from RF and 802.11 fundamentals to
professional Wi-Fi penetration testing and defence — capturing and cracking WPA2, assessing WPA3-SAE,
attacking and hardening WPA2/WPA3-Enterprise, building rogue APs, and reporting like a pro. Every
attack is learned in a safe lab against equipment you own, paired with the defence that stops it and
measured against a hardened configuration.

Three lab paths let you learn with **no wireless hardware** (recorded captures), with **virtual radios**
(`mac80211_hwsim`), or with **real adapters** — each honestly scoped. Aligned with most OffSec PEN-210
(OSWP) objectives and modernised: WPA3, PMKID, hashcat `-m 22000`, 802.1X/EAP, and management-frame
protection, with legacy ciphers covered only as brief historical notes. It covers most OSWP objectives
with a disclosed gap list; it does not promise an exam pass. Prerequisites: comfort with the Linux
shell and TCP/IP basics (a readiness check and prep path are in Module 0).

See `plan.md` for the brief and `curriculum/course-outline.md` for the full module map.

> [!WARNING]
> Every technique here is for networks and devices **you own and control**, in an isolated lab.
> Intercepting, deauthenticating, or attacking any network you are not authorised to test is illegal
> in essentially every jurisdiction. Read `PUBLISHING_WARNING.md` before publishing.

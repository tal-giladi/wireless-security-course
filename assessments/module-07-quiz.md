# Module 7 quiz — WPA3-SAE

This quiz checks the precise, qualified claims this module insists on: SAE yields no offline-crackable
hash, transition mode is the real downgrade surface, Dragonblood is a mitigated implementation class,
OWE encrypts without authenticating the network, and a hardened WPA3 deployment is SAE-only with PMF
required and H2E.

- **Format:** multiple choice, one correct answer each.
- **Pass mark:** 70%.
- **Covers:** [07.1 SAE](../lessons/module-07/lesson-01.md),
  [07.2 transition mode](../lessons/module-07/lesson-02.md),
  [07.3 Dragonblood](../lessons/module-07/lesson-03.md),
  [07.4 OWE](../lessons/module-07/lesson-04.md),
  [07.5 configuring WPA3 securely](../lessons/module-07/lesson-05.md).

The questions reward accuracy over headlines — a hardened WPA3 network and a correctly-scoped
"not exposed to Dragonblood" verdict are valid, high-value answers.

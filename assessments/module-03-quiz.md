# Module 3 quiz — Building your lab (three paths)

This quiz checks that you can set up and choose between the three lab paths honestly: picking recorded,
virtual, or physical by what an exercise actually needs, verifying supplied captures before you trust
them, reproducing protocol flows on simulated radios, and bringing up (or deliberately not bringing up)
real hardware on a Windows-hosted VM.

- **Format:** multiple choice, one correct answer each.
- **Pass mark:** 70%.
- **Covers:** [03.1 choosing your path](../lessons/module-03/lesson-01.md),
  [03.2 recorded-data setup](../lessons/module-03/lesson-02.md),
  [03.3 virtual labs with mac80211_hwsim](../lessons/module-03/lesson-03.md),
  [03.4 the physical rig](../lessons/module-03/lesson-04.md),
  [03.5 Windows-hosted VMs and USB passthrough](../lessons/module-03/lesson-05.md).

The questions are scenario-based: they ask you to decide a path, diagnose a setup failure, and state
honestly what a given path proves. If you find yourself defaulting to the physical path for everything,
or treating "it does monitor mode" as proof of injection, re-read 03.1 and 03.4 before moving on — the
recon, capture, and cracking modules all assume you can choose a path and verify your tools and gear.

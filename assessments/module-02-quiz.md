# Module 2 quiz — Wi-Fi security protocols & the secure baseline

This quiz checks that you can tell the Wi-Fi security options apart by what they authenticate and encrypt, reason about where crackable key material does and does not come from, apply the secure baseline, and recognise deprecated ciphers as findings.

- **Format:** multiple choice, one correct answer each.
- **Pass mark:** 70%.
- **Covers:** [08 · the protocol family](../lessons/module-02/lesson-01.md),
  [09 · key hierarchies](../lessons/module-02/lesson-02.md),
  [10 · the secure baseline](../lessons/module-02/lesson-03.md),
  [11 · legacy & deprecated](../lessons/module-02/lesson-04.md).

The questions are scenario-based: they ask you to apply the distinctions (OWE vs authentication, SAE vs offline cracking, PMF's limits, transition-mode downgrade, the vulnerable-vs-hardened baseline) rather than to recall definitions. These distinctions underpin the attack and defence modules that follow, so if you miss several, re-read the relevant lesson before continuing.

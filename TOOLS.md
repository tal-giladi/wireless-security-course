# Tools & versions

The pinned software inventory for this course. **Versions are marked `VERIFY` until confirmed on a
real build** — never trust an invented version or date. When you set up your lab (Module 3) you record
the versions you actually installed in your own notes; the course teaches techniques, and names the
tool and the flag, so a newer version with a changed flag is a troubleshooting exercise, not a wall.

> [!NOTE]
> This file is a reference page, not a lab. The per-lab "known starting state" sections state which of
> these tools that lab needs and on which path (R recorded-data · V virtual · P physical).

## What is deliberately NOT pinned / NOT shipped

- **WEP tooling** — WEP is a link-only "legacy & deprecated" note (`lessons/module-02/lesson-04.md`),
  no lab. OSWP-prep gap disclosed in `curriculum/course-outline.md`.
- **Large binaries, captures, wordlists, models** — never committed to git (`.gitignore`). Captures are
  generated by the scripts in `labs/common/` and recorded with provenance + SHA-256 at generation time;
  wordlists are downloaded by a setup script.

## Hardware

Adapters, APs, and clients are specified in `curriculum/lab-matrix.md` (chipset-first buying rule;
separate monitor / injection / AP-mode columns). The physical path is **optional** — the course is
completable on the recorded-data and virtual paths with zero purchases.

## How to (re)generate and verify

```bash
sudo ./hwsim-up.sh 3
sudo ./gen-captures.sh          # writes ./captures/ and ./captures/CHECKSUMS.txt
sudo ./hwsim-down.sh
sha256sum -c captures/CHECKSUMS.txt   # re-verify later
```

After a verified run, paste the checksums from `captures/CHECKSUMS.txt` into the table above, set each
row to `verified <YYYY-MM-DD>` (the real date), and commit the capture files (they are a few KB each).

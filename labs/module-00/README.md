# Module 0 labs — onboarding

Module 0 has no attack lab. Its "labs" are the two planning documents you fill in once and reuse for
the rest of the course, plus the shared tooling in `labs/common/` (added to every module zip).

## In this module's zip

- This README.
- From `labs/common/`: `setup-check.sh`, `reset-lab.sh`, `hwsim-up.sh`, `hwsim-down.sh`, and the
  capture/wordlist generators you'll use from Module 6 onward.

## Do this now (recorded-data path — no hardware)

1. Copy `templates/authorisation-template.md` into your notes and fill in your own lab's scope,
   allowlist, transmission limits, and stop conditions (lesson 00.3).
2. Copy `templates/lab-notebook-template.md`; you'll add one entry per lab from here on, recording the
   **path** you used (R/V/P) and what it proved.
3. If you have a Linux environment already, run `labs/common/setup-check.sh` to see which tools you have
   and record the versions. (You'll build the full lab in Module 3.)

## Success criteria

- A completed scope/authorisation sheet for equipment you own.
- A lab notebook started, with your chosen path noted.
- No tools run against any network — Module 0 is planning only.

## Cleanup

None — nothing was transmitted or captured.
